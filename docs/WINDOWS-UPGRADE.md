# Windows editor upgrade tracking

The accepted scope is staged delivery, local processing, and ten layer-effect families.
Original author: Robbie Tilton / Compositor. Original copyright and MIT license remain unchanged.

| Stage | Scope | Status |
|---|---|---|
| 0.3 | Complete selections, dragging, clipboard, context menus, tool properties and basic tools | Implemented and verified in 0.3 preview; manual checks listed in validation record |
| 0.4 | WebGPU, worker processing, document v2 and compatibility migration | Implemented in 0.4 preview; Canvas blur/export, 8-bit editing and other limits documented in validation |
| 0.5 | Editable text, paths, shapes and free transforms | Pending |
| 0.6 | RAW development, local healing and local background removal | Pending |
| 0.7 | Ten effects and integrated PSD preservation | Pending |

Every stage requires interaction tests, save/reopen checks, a portable Windows build, documentation and checksums. Pending stages must not be advertised as implemented. Photoshop interoperability remains unverified until checked in Photoshop.
