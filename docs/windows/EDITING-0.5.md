# 0.5 文字、路径与自由变换

本版是 Robbie Tilton / Compositor 的非官方 Windows 改写。原始版权、MIT 许可证及 macOS 源码保留。正常编辑不需要联网。

## 文字

按 **T**，在画布点击创建点文字，拖出矩形创建段落文字。选中文字层后，再点击其范围或使用“编辑文字”可修改内容。支持中英文、字体名称、字号、颜色、字距、行距、对齐、粗体和斜体。缺少字体时显示系统替代提示；段落溢出会提示并裁切。字体按名称填写，字体替代检测是度量启发式判断，不保证某字体覆盖所有字符。

编辑框使用原生 HTML 文本输入。组合输入期间禁止提交，Ctrl+Enter 应用；取消不改变文档。Windows 原生输入法候选窗完整流程仍未验收，不能把测试中的中文插入和组合事件检查等同于该验收。

每层使用统一文字样式，最多 4000 字符；尚无富文本区间样式、竖排、文字沿路径、专业排版或字体文件嵌入。段落按字符自动折行。编辑导入的 PSD 文字后，字体和行布局可能与原缓存预览不同。

## 钢笔、形状与蒙版

- **P**：点击添加锚点，按住拖动生成贝塞尔方向手柄。编辑时拖动锚点或手柄；Alt 拖动断开手柄联动。属性栏可插入、删除节点，切换闭合、填充、描边颜色和线宽。
- **U**：拖动创建矩形、椭圆、直线或 3–12 边多边形。形状也是可编辑路径。
- **Enter** 提交路径，**Esc** 取消。每次提交对应一次撤销。
- “路径转选区”使用闭合区域；“作为下一层矢量蒙版”作用于列表中紧邻下方的像素层，隐藏路径层并选中目标蒙版。使用“编辑路径 / 矢量蒙版”继续修改。

每层目前只有一条路径，最多 1000 节点；填充为纯色、偶奇规则，描边为居中圆帽圆角。没有复合路径布尔运算、虚线和多重描边。带栅格蒙版的路径在重新塑形前需要移除蒙版。

## 自由变换

选中图层后按 **Ctrl+T**。拖动控制框缩放、旋转，拖动框内移动。属性栏提供比例约束、宽高、相对旋转角和相对倾斜角；Shift 拖动也约束比例。模式可切换为四角透视或 3×3 网格。

拖动时更新控制线，松开后在后台计算像素预览；不是每一帧都计算完整变形。Enter 提交、Esc 取消。无效翻折和退化网格会报错，原文档不变。3×3 网格使用八个三角形的分片仿射插值，尚非 Photoshop 的平滑贝塞尔网格。

`.cwin` 保存变形前图像、原蒙版和控制点，可再次编辑或重置。重置恢复原图和原蒙版，保留当前左上位置；需要完全恢复原先位置时使用撤销。已变形文字或路径先重置变形，再修改内容。透视/网格参数切换会从已提交图层开始新的预览，请先提交需要保留的修改。

## 像素修画与保存

文字、路径、矢量蒙版和变形层的相关像素编辑受保护。需要画笔修画、擦除、填充或移动选区内容时，先显式“栅格化”；栅格化本身可撤销。普通文字层的独立栅格蒙版仍可修画。

先保存 `.cwin`，再导出 PSD。不要在 0.4 中编辑并保存 0.5 项目，否则旧版本无法保留新增的变形原图资源。继续支持读取 v1 项目并另存 v2 副本；不修改原版 `.comp` 格式。

## PSD 支持范围

支持统一样式横排文字、简单单路径、纯色形状与矢量蒙版的参数保留。复杂文字、多路径、渐变/图案填充、特殊描边等展示转换说明。文字或路径带像素滤镜，以及所有自由变形，导出为栅格副本；变形层名称附加 `[raster deformation]`，完整参数留在 `.cwin`。

文字与路径同时保留缓存图像，导出仍以 8-bit RGB 为范围。写入库本身不负责生成 Photoshop 文字缓存，渲染和回读受支持范围有限，参见 [ag-psd 官方说明](https://github.com/Agamnentzar/ag-psd)。**未完成 Photoshop 实机互操作验收**，本地往返通过不等于 Photoshop 中一致。高级图层效果、剪贴关系完整保留与其他 PSD 结构继续属于后续阶段。

Camera Raw、内容识别修复、自动抠图和十类高级图层效果尚未实现，本版没有放置可点击的空入口。
