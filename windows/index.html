Compositor Windows · 0.3 preview

An unofficial Windows adaptation of Robbie Tilton’s open-source Compositor. The native Mac application is preserved in the source repository.

PSD compatibility

8-bit RGB PSD: pixel layers, groups, visibility, opacity, common blend modes and raster masks. Levels, Curves, Exposure and Invert adjustment layers retain their Photoshop parameters, with an approximate Windows preview. Export writes a new layered PSD; editable Windows filters are baked into each layer’s pixels. Save .cwin to retain filters.

Text, smart objects and vectors use cached pixels. Other adjustment layers, clipping, layer styles and unsupported rendering features are reported before import; use merged preview when fidelity matters. CMYK, 16/32-bit and PSB are rejected. Photoshop pixel-perfect color matching is not guaranteed. Original .comp projects are not supported in this preview.

Tools & shortcuts

M rectangle / Shift+M ellipse · L lasso / Shift+L polygon · W wand · C crop · G gradient / Shift+G bucket · H hand · Z zoom. Ctrl+C copy · Ctrl+Shift+C merged copy · Ctrl+X cut · Ctrl+V paste · Ctrl+A select all · Ctrl+Shift+D invert selection. Right-click canvas or layers for actions. Drag layer rows to reorder or enter groups. Move selection pixels: Enter apply, Esc cancel.

V move · B brush · E eraser · S clone stamp (Alt-click source) · M rectangle selection · I color picker. Ctrl+O open · Ctrl+S save project · Ctrl+Shift+S export PSD · Ctrl+Z undo · Ctrl+Shift+Z redo · Ctrl+J duplicate · Ctrl+D deselect. Click a mask thumbnail to paint black/white coverage. Double-click a filter to edit it.

File limit: 256 MB. Canvas: 16 MP. Total imported source/mask pixels: 64 MP. Undo: up to 20 steps; large documents reduce available history. This preview is unsigned.
